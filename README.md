# Ariadna-Developer-Portafolio
Soy desarrolladora de software con experiencia construyendo soluciones empresariales y una fuerte orientación al aprendizaje continuo. Me gusta entender no solo cómo desarrollar una funcionalidad, sino también el contexto del negocio, la arquitectura y el impacto que genera.

He trabajado principalmente con tecnologías como C#, SQL, Dynamics 365, Power Platform y aplicaciones web basadas en MVC, además de explorar herramientas modernas como React, TypeScript y servicios de Azure. Disfruto analizar problemas, diseñar soluciones estructuradas y convertir requerimientos en implementaciones funcionales.

Me considero una persona adaptable, con iniciativa y aprendizaje autónomo. Mi objetivo profesional es seguir creciendo hacia posiciones de liderazgo técnico y arquitectura de software, desarrollando soluciones escalables, mantenibles y alineadas a objetivos de negocio.
